# Thesis project brief

Keep this file in your thesis project root. Replace the example values with your
own and remove fields you do not need. This is context for your assistant, not
an executable configuration file. All relative paths start at this file.

## Research and writing

- Working title: My thesis
- Discipline: Your field
- Main research question: The question this thesis answers
- Intended contribution: What the work aims to establish
- Audience: Newcomers to the field for orientation; specialists for methods
- Language and spelling: English; choose the project's spelling convention
- Voice: Preserve the author's voice; follow institutional pronoun conventions
- Citation style: Use the existing manuscript style
- Degree/institution requirements: Link to the current requirements, if relevant

## Files

These paths illustrate a layout, not directories the installer creates.

- Manuscript: `manuscript/`
- Entry document: `manuscript/main.tex`
- Bibliography: `manuscript/references.bib`
- Original PDFs: `literature/pdfs/`
- Markdown reading copies: `literature/markdown/`
- Reading notes: `literature/notes/`
- Writing guidelines: `guidance/`
- Supervisor feedback: `feedback/`
- Evidence and results: `results/`
- Figure sources: `figures/`
- Presentation: `presentation/`

## Commands and constraints

- Build command and working directory: Describe your existing workflow
- Python environment: Use the project's environment; no particular name required
- Evidence already verified: Point to existing notes, if any
- Known extraction defects: Record affected documents and passages
- Excluded or deferred work: State what must stay outside the current storyline
- Data sharing and AI-use requirements: Record applicable project rules

Never put passwords, API keys, private participant data, or confidential feedback
in a public brief. Keep private material outside the shareable skill bundle.
